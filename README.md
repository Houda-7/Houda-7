### Projects
 
**[RINAM Network Security — ONDA](https://github.com/Houda-7/RINAM-network-security-onda)**  
Design of an isolated network lab to secure critical airport data flows (radar telemetry, VCS).
- Network segmentation into 3 zones (Zero-Trust) using 802.1Q VLANs and inter-VLAN routing
- Stateless firewalling with extended ACLs (Default Deny rule)
- Hardened administrative access with SSHv2 (RSA 1024-bit) and Telnet disabled
- Full simulation in Cisco Packet Tracer with a documented proof of concept
